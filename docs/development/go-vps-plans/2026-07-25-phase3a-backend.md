# Phase 3a Backend (Profile & Notification-token) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the `profile` and `notification`-token slices behind the Go API — eager provisioning fan-out, an internal-user resolution middleware, an R2 presigned-upload adapter, and consistent Go-maintained `updated_at` writes — so a signed-in user is fully provisioned and can manage their profile and FCM tokens through the Go API.

**Architecture:** Extends the Phase 2 identity spine. First-sighting provisioning fans out (in one transaction) to `profiles` (generated username) + `notification_settings`. Internal-user resolution is promoted from the `/me` handler into an `identity` middleware exposing `CurrentUser(ctx)`. Two new features (`profile`, `notification`) own their tables; a new `platform/r2` adapter isolates the R2/S3 SDK. Go-owned Store SQL explicitly maintains `updated_at` on every mutable write.

**Tech Stack:** Go (stdlib-first: `net/http`, `database/sql` over the pgx driver, `log/slog`), Atlas (table-only schema with no functions or triggers initially), Postgres. New dependency: AWS S3 SDK v2 (`github.com/aws/aws-sdk-go-v2`) for R2 presigning — R2/S3 types stop at `platform/r2`.

**Spec:** `docs/designs/2026-07-25-phase3a-profile-notification-design.md` (authoritative for exact contracts, validation rules, and decisions D1–D11). This plan targets Phase 2's merged backend (`internal/{core,platform/auth,identity}`, `internal/api`).

## Global Constraints

- **Stdlib-first Go.** Only new dependency this plan adds is the AWS S3 SDK v2, used **only** inside `internal/platform/r2`. Domain/service/handler code never imports it.
- **Atlas table-only.** Schema is `backend/schema/<feature>/NN_name.sql` (plain `CREATE TABLE`, numeric filename prefix for FK load order), with no functions or triggers initially.
- **`updated_at` is Go-maintained.** INSERT relies on `DEFAULT now()`; every mutable Store `UPDATE` and `ON CONFLICT DO UPDATE` explicitly sets `updated_at = now()`.
- **`updated_at` uses `now()`** = last modifying transaction time (do not switch to `statement_timestamp()`).
- **Authz by internal UUID.** Every profile/fcm-token operation is scoped to `identity.CurrentUser(ctx).ID`. Cross-user access is impossible by construction and covered by isolation tests.
- **Stable error envelope** (Phase 2 `httpserver.WriteError`): `{ error: { code, message, requestId } }`. New codes: `invalid_argument` (400), `username_taken` (409), `invalid_timezone` (400), `rate_limited` (429).
- **`profiles.id` = PK & FK → `users(id)`**; the profile API/DTO is **idless** and carries **no Stripe field**.
- **Avatar 5 MiB is best-effort** (client pre-check + finalize `HEAD` backstop + per-user rate limit + inline delete-previous + future Phase 4 sweep). Not a hard guarantee. See spec §4.6.
- **Migrations** are generated by Atlas from `backend/schema/`, not hand-written (project rule). Run `make` targets; keep `make test` green with `-count=1`.
- **Naming (Option E):** feature files `domain.go` / `service.go` (`Service`) / `store.go` (`Store`) / `handler.go` (`Handler`); DTO-equivalent response structs live in the handler.

```go
package identity

import (
	"context"
	"log/slog"
	"net/http"

	"github.com/cloveclovedev/peppercheck/backend/internal/core/httpserver"
	"github.com/cloveclovedev/peppercheck/backend/internal/platform/auth"
)

type ctxKey int

const userKey ctxKey = 0

// CurrentUser returns the internal user resolved by NewMiddleware.
func CurrentUser(ctx context.Context) (User, bool) {
	u, ok := ctx.Value(userKey).(User)
	return u, ok
}

// NewMiddleware resolves the verified Identity (placed by the auth middleware)
// to the internal user, provisioning on first sighting, and stores it in the
// context. It runs after auth.Middleware. A resolve failure is a 500 (logged);
// a missing Identity is a 401. A nil logger falls back to slog.Default().
func NewMiddleware(svc *Service, logger *slog.Logger) func(http.Handler) http.Handler {
	if logger == nil {
		logger = slog.Default()
	}
	return func(next http.Handler) http.Handler {
		return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
			id, ok := auth.IdentityFrom(r.Context())
			if !ok {
				httpserver.WriteError(w, r, http.StatusUnauthorized, httpserver.CodeUnauthenticated, "missing identity")
				return
			}
			u, err := svc.ResolveOrProvision(r.Context(), id.Issuer, id.Subject)
			if err != nil {
				logger.LogAttrs(r.Context(), slog.LevelError, "resolve_user_failed",
					slog.String("request_id", httpserver.RequestIDFrom(r.Context())),
					slog.Any("error", err))
				httpserver.WriteError(w, r, http.StatusInternalServerError, httpserver.CodeInternal, "could not resolve user")
				return
			}
			next.ServeHTTP(w, r.WithContext(context.WithValue(r.Context(), userKey, u)))
		})
	}
}
```

```go
func (s *Store) CreateWithIdentity(ctx context.Context, issuer, subject string,
	provision func(ctx context.Context, tx *sql.Tx, userID string) error) (User, error) {
	tx, err := s.db.BeginTx(ctx, nil)
	if err != nil { return User{}, fmt.Errorf("begin: %w", err) }
	defer func() { _ = tx.Rollback() }()

	var u User
	if err := tx.QueryRowContext(ctx,
		`INSERT INTO public.users DEFAULT VALUES RETURNING id, status, created_at, updated_at`,
	).Scan(&u.ID, &u.Status, &u.CreatedAt, &u.UpdatedAt); err != nil {
		return User{}, fmt.Errorf("insert user: %w", err)
	}
	if _, err := tx.ExecContext(ctx,
		`INSERT INTO public.user_identities (user_id, issuer, subject) VALUES ($1,$2,$3)`,
		u.ID, issuer, subject); err != nil {
		var pgErr *pgconn.PgError
		if errors.As(err, &pgErr) && pgErr.Code == "23505" { return User{}, ErrNotFound }
		return User{}, fmt.Errorf("insert identity: %w", err)
	}
	if provision != nil {
		if err := provision(ctx, tx, u.ID); err != nil {
			return User{}, fmt.Errorf("provision: %w", err)
		}
	}
	if err := tx.Commit(); err != nil { return User{}, fmt.Errorf("commit: %w", err) }
	return u, nil
}
```

```go
func (s *Store) ProvisionInTx(ctx context.Context, q database.Querier, userID string) error {
	for attempt := 0; attempt < 5; attempt++ {
		if _, err := q.ExecContext(ctx, `SAVEPOINT sp_username`); err != nil {
			return fmt.Errorf("savepoint: %w", err)
		}
		_, err := q.ExecContext(ctx,
			`INSERT INTO public.profiles (id, username) VALUES ($1, $2)`, userID, genUsername())
		if err == nil {
			_, _ = q.ExecContext(ctx, `RELEASE SAVEPOINT sp_username`)
			return nil
		}
		var pgErr *pgconn.PgError
		if errors.As(err, &pgErr) && pgErr.Code == "23505" {
			if _, rbErr := q.ExecContext(ctx, `ROLLBACK TO SAVEPOINT sp_username`); rbErr != nil {
				return fmt.Errorf("rollback savepoint: %w", rbErr)
			}
			continue
		}
		return fmt.Errorf("insert profile: %w", err)
	}
	return errors.New("username generation exhausted after 5 attempts")
}

func genUsername() string {
	var b [4]byte
	_, _ = rand.Read(b[:]) // crypto/rand
	return "user_" + hex.EncodeToString(b[:]) // 13 chars, within 2..20
}
```
